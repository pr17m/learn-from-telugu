# Notes for AI coding assistants
- Content lives in `src/`; never hand-edit `www/index.html`. Run `npm run build` after any change in `src/`.
- Publishing (GitHub, web app, Google Play, App Store): follow `DEPLOY.md` phase by phase and keep `DEPLOY-PROGRESS.md` up to date.
- Never commit keystores, `android/keystore.properties` or other secrets.
